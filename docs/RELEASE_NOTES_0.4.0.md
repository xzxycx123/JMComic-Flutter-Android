# JMComic v0.4.0

> 更新LiquidGlass以及一些UI bug
## LiquidGlass
- **界面**：关键词、「开始阅读」「下载」「查看全部评论」改为连续曲率圆角矩形。 Dock「首页」「我的」使用LiquidGlass，首页分类选中后整块填橙。返回按钮缩小但保留触控范围，收藏与分享、登录卡片与收藏入口均拉开间距，相关推荐标题下方不再使用透明玻璃底。

- **阅读器**：滑块拖动时不再盖住左侧进度文字，松手直接跳到目标页，不再重播滑动动画。顶部按钮缩小，点击「线路 3」一类按钮会从按钮位置平滑展开浮层。

- **搜索**：结果卡片同时显示作者和小标签；点击详情标签会立即按关键词搜索，纯数字标签也不会误跳车号。Metal 和 LiquidGlass 都支持长按历史条目打开菜单，只有点「删除」才移除该条。

## 功能更新
1. 搜索页作品有小标签
2. 详情页点标签自动搜索这个标签
3. 搜索记录长按某个按钮弹出删除标签
