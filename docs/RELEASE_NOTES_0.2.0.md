# JMComic 0.2.0 · 登录与收藏同步

> GPL-3.0 · Android 8.0+（minSdk 29）· 62.5 MB · universal APK（arm64-v8a / armeabi-v7a / x86_64）

## 本次新增

- **登录 + 收藏同步**：本地账本优先，登录后与服务端对账；`POST /favorite` 是 toggle，客户端会核对返回的 `type` 并在不符时反向补发一次，避免静默丢收藏。
- **收藏页**（我的 → 我的收藏）：文件夹（默认 / 自建）、按收藏/更新时间排序、更新角标、「有更新」提示；详情页收藏支持**撤销**。
- **不保存密码**：登录态只靠 cookie；冷启动一次校验，失效自动回本地模式；退出登录清会话/cookie/outbox，本地收藏保留并标记「仅本地」。
- **阅读器 HUD 适配状态栏**：顶部条用 SafeArea 下移，不再和系统时间/信号图标重叠。
- **Dock 两档**：首页 / 我的；下载与历史收进「我的」二级菜单。
- **启动更快**：复用上次成功线路（零发现请求）+ 上次首页缓存秒开，后台拉新后整体替换。
- 许可证改为 **GNU GPL v3.0**（Copyright (C) 2026 xzxycx）。

## 安装

1. 下载 `JMComic-0.2.0-release.apk`；
2. 允许「安装未知来源应用」后安装（debug keystore 签名，仅自用，不上架商店）；
3. 可选：允许通知权限以显示下载进度。

```bash
adb install -r JMComic-0.2.0-release.apk
```
