#控件操作逻辑接口 / 参数
1首页搜索框点开搜索页（不直接发请求）；输入框聚焦、键盘弹出无（本地路由）
2主题切换系统 / 浅色 / 深色，写本地偏好并即时重建shared_preferences
3首页轮播promote 前 6 个模块各取首项；5s 自动轮播，手滑后暂停 8s；点击进详情/promote
4分类 chips切换分类并重置分页，首项「全部」= c=0/categories → /categories/filter?c=<id>
5分节横滑 / 更多模块一行横滑；「更多」进该模块列表（type=category_id 时带 filter_val）/promote
6最新上架 横滑点卡片进详情/latest?page=1（80/页）
7双列瀑布流卡片封面 3:4 + 标题；点击进详情并做 Hero 过渡；封面由 id 现拼/categories/filter?page=N&order=&c=0&o=mr；封面 {img_host}/media/albums/{id}_3x4.jpg
8下拉刷新 / 触底翻页下拉重置第 1 页并归零；距底 500px 拉下一页，失败留旧内容 + 底部重试同上，page+1；空 content 终止
9底部 Dock三档固定：首页 / 我的 / 下载；切换保留各自栈与滚动位置本地路由（StatefulShellRoute）
10详情返回回上一页并保留列表位置本地导航
11下载（详情次按钮）当前 albumId 入队（并发 3），切到下载 tab 并高亮新任务/album?id= → /chapter?id= → /chapter_view_template → /media/photos/{photoId}/{file}
12章节点「阅读」进阅读器，定位到该章节第 1 页/chapter?id= 的 images[]
13收藏v1 存本地；登录态下改调 toggle 收藏接口（接口已探明，留 v2）本地 Hive；登录后 POST /favorite {aid}
14车号输入框多行/逗号/空格/分号分隔；实时显示「有效 / 忽略」并去重本地 JmIdParser
15加入队列只收解析成功项；同 albumId 在队列则提示「已在队列中」；超 3 并发进排队本地队列（队列 3 / 单任务 3 图）
16分段筛选全部 / 进行中 / 已完成，前端过滤本地记录表
17任务卡操作取消 = 停任务 + 删临时目录；重试 = 同 id 重跑；打开 = 系统查看器；删除 = 删记录（PDF 保留）本地；导出 Documents/JMComics/JM{id} - {标题}.pdf
18线路与探测显示 apiHost / imgHost；点击重跑域名发现 + /setting，失败自动换线3 个 TOS 域名单 → /setting
19主题 / 存储设置主题即时生效；下载目录只读可复制本地
20清理缓存清封面磁盘缓存 + 记录缓存，二次确认后显示释放字节本地
21搜索页判定与结果本地先判：纯车号 / JM 前缀 / album|photo 链接 → 直接推详情；否则 GET 搜索出结果网格（可翻页、可切网格/列表）车号：/album?id=；关键词：/search?main_tag=0&search_query=…&page=1&o=mr&t=a（命中车号返回 redirect_aid 也跳详情）
22详情「开始阅读」主按钮，进阅读器；有进度记忆时文案变「继续阅读 · 第 N 页」并直达/chapter?id= + 本地 progress:
23阅读器三分区点击左 30% 上一页 / 中 40% 显隐 HUD / 右 30% 下一页；首末页回弹 + 轻震；双指缩放时禁用本地；预加载 ±2 页
24阅读器 HUD顶部退出 + 标题页码 + 模式切换；底部进度条可拖，拖动浮气泡「第 N 页」，松手跳页并落库；3s 自动隐藏/media/photos/{photoId}/{file} + scramble_id 还原

加载时序（真实调用链）

冷启动
├─ 域名发现：3 个 TOS 地址 → 解密 {Server:[…]}   失败回落内置 6 域名
└─ /setting                                  → cookie ×5 + img_host + jm3_version

首页（并行 4 个请求，谁先回先渲染）
├─ /promote                    → 8 个模块（轮播取前 6 个首项）
├─ /latest?page=1              → 80 条「最新上架」
├─ /categories                 → 10 个分类 chips
└─ /categories/filter?page=1&order=&c=0&o=mr → 80 条瀑布流

搜索（GET）
├─ 本地判定为车号 → 直接 /album?id=，不进结果页
└─ 关键词 → /search?main_tag=0&search_query=…&page=1&o=mr&t=a
             └─ 若返回 redirect_aid → 同样跳 /album?id=

阅读
├─ /album?id=      → series 空则章节=专辑 id
├─ /chapter?id=    → images[]（如 00001.webp …）
├─ /chapter_view_template → scramble_id（实测 220980）
└─ /media/photos/{photoId}/{file} → 切片还原 → 左右翻页 / 上下滚动

下载（队列 3 并发，单任务 3 图并发）
├─ 章节清单预取 → 进度分母确定
├─ 逐页下载 + PNG 重编码（isolate）
├─ 合成 PDF（一页一图，页尺寸=图尺寸）
└─ 落盘 Documents/JMComics/JM{id} - {标题}.pdf，重名 (2)

接口速查 2026-11-14 实测

端点关键参数返回
/setting—cookie ×5、img_host、jm3_version
/promote—顶层数组，8 模块，各 3~30 项
/latestpage顶层数组，80 条/页
/categoriespage10 个顶层分类 + 子分类
/categories/filterpage,order=,c,o{total,content[]}；o=mr/mv/mv_m/mv_w/mv_t/md/mp
/searchsearch_query,page,o,t,main_tag{total,content[]}；命中车号给 redirect_aid
/albumidname,author,tags,series[],total_photos…
/chapterid{id,name,images[]}
/chapter_view_templateid,mode,page,app_img_shunt,express,vHTML → var scramble_id = N;

协议来源：JMComic-Crawler-Python 的 JmApiClient（src/jmcomic/jm_client_impl.py 里的 API_SEARCH / API_CATEGORIES_FILTER / API_ALBUM / API_CHAPTER / API_SCRAMBLE）；/promote、/latest、/categories 为本地实测补充。列表接口 image 恒为空串，封面需按 {img_host}/media/albums/{id}_3x4.jpg 自拼。
