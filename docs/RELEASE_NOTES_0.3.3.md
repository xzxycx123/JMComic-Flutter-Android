# JMComic 0.3.3 发布说明

> 版本：`0.3.3+7` · 平台：Android 8.0+（minSdk 29） · 产物：`dist/JMComic-0.3.3-release.apk`（68,412,213 B / 65.2 MB，SHA-256 `2d6f0126edcd723bb846bbf2baba52be94c7d223bcac77a18b1dbe445d3f1644`）
> 上一版：`0.3.2+6`

## 修复

- **阅读器进度条拖了没反应**：拖动时改的是「当前页」本身，松手时 `_goToPage` 发现目标和当前页相同就直接 return，等于什么都没发生。现在拖动只更新 HUD 预览页，松手才真正翻页。
- **「已收藏」提示不消失**：连点收藏会往队列里排一串 SnackBar，看着像永久停留。现在先 `clearSnackBars()` 再提示，并固定 2 秒。
- **评论全部带「剧透」标**：实测 `/forum` 返回的 `spoiler` 字段**恒为 `"1"`**（不是剧透标记，更像服务端的处理状态位），已不再按它渲染标签；写评论的「含剧透」开关保留。
- **双指拖动乱跑**：之前只有放大后才锁翻页，双指刚落下时横向拖动会先把页面翻走。现在任一页检测到 **≥2 根手指按下** 就锁住翻页/滚动，双指捏合与平移都交给图片层。

## 新增

- **阅读历史**（我的 → 阅读 → 阅读历史）：按最近阅读倒序，显示封面 / 标题 / 章节 / 进度条 / 百分比 / 时间；点一条直接续读，长按可删单条，右上角可清空。阅读器写进度时会顺手记下专辑与章节标题。
- **内置 PDF 阅读器**：下载完成的 PDF 现在直接在 App 内打开（Android 原生 `PdfRenderer`，无需第三方插件、不用装外部阅读器）。支持左右翻页 / 上下滚动、双指缩放、双击放大、HUD 进度条与跳页；HUD 右侧显示当前模式，点它（或顶栏模式图标）弹出**阅读模式选择**面板。渲染失败可一键重试，或退回「用其它应用打开」。
- **搜索排序**：搜索结果上方新增排序条 —— **最新更新（时间）/ 阅读数 / 人气 / 最新上架**，走服务端 `o` 参数（实测四种顺序结果不同），切换即从第 1 页重拉。

## 其它

- 阅读进度记录新增 `albumTitle` / `chapterTitle` 字段（旧记录自动回落成 `JM<车号>`，无需迁移）。
- 新增 `tools/probe_comments_search.ps1`：复核评论 `spoiler` 取值与 `/search?o=` 各排序。
