# JMComic v0.4.1

本版集中调整 LiquidGlass 内容层级、作品信息展示、评论过滤、续读记录和每日签到体验。

## 界面与交互

- 下载页的输入区与任务卡片改用清晰的实色内容表面，玻璃保留给导航和控制层，减少滚动列表中的折射嵌套。
- 首页作品卡片增加紧凑标签与左下角喜欢数；标签会去重、清理无效值并限制长度。
- 首页排序栏压缩高度，支持一键收起/展开；收起后仍保留当前排序入口。
- 分类、排序、详情标签及主要操作按钮统一为更紧凑的药丸形。
- 详情页顶部显示 JM 号，标签高度降低，点击作者可直接搜索该作者。
- 相关推荐继续复用统一作品卡片，同步展示标签与喜欢数。

## 评论与阅读

- 默认隐藏包含超过两个 emoji 的疑似推广评论，正常评论与服务端原始数据不受影响。
- 展开评论并滑到当前列表底部后，可通过「显示可能存在广告的评论」手动找回被隐藏内容。
- 阅读进度在 HUD 退出、系统返回和返回手势下都会记录；旧页异步写入不会覆盖新进度。
- 返回详情后立即显示「继续阅读 · 第 N 页」，包括第 1 页和最后 1 页；多章作品仍按章节独立记录。

## 每日签到

- 「我的」新增每日签到入口和今日状态、连续天数摘要。
- 签到页提供月历、月份切换、今天高亮和已签日期标记。
- 展示本月、累计和连续签到统计；未来日期不可签到，同一天重复操作不会重复记录。
- 签到数据保存在本机，可离线使用。

## 安装

下载 Release 附件：

`JMComic-0.4.1-release.apk`

源码构建后，APK 同时归档到仓库的 `dist/JMComic-0.4.1-release.apk`。
