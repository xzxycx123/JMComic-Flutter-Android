# JMComic 0.3.3.1 发布说明

> 版本：`0.3.3.1`（versionCode `8`） · 平台：Android 8.0+（minSdk 29） · 产物：`JMComic-0.3.3.1-release.apk`（68,412,713 B / 65.24 MB，SHA-256 `8d8609509892fc1554d28ec73c6cef314662de077dff9557e5ea0b89b5bc9588`）
> 上一版：`0.3.3`（versionCode `7`）

## 这一版是什么

0.3.3 的**重发版**，功能清单与 0.3.3 完全一致，只是把 0.3.3 之后那次「自绘提示 toast」的收尾改动一起带上（0.3.3 的正式包是在那次改动之前构建的）。

## 与 0.3.3 的差别

- **提示 toast 收尾**：气泡改为细胶囊 + 可选图标，退场先播 `dismiss()` 动画再移除 Overlay，不再「啪」地一下消失；入场 / 退场时长调整为 240ms / 160ms。
- 版本号 `0.3.3.1`、versionCode `8`，可直接覆盖安装 0.3.3（无需卸载）。

## 功能一览（同 0.3.3）

- **阅读历史**（我的 → 阅读 → 阅读历史）：按最近阅读倒序，封面 / 标题 / 章节 / 进度 / 时间；点一条续读、长按删单条、右上角清空。
- **内置 PDF 阅读器**：下载完成的 PDF 直接在 App 内打开（Android 原生 `PdfRenderer`），左右翻页 / 上下滚动、双指缩放、双击放大、HUD 进度与跳页，可切换阅读模式或退回外部应用。
- **搜索排序**：最新更新 / 阅读数 / 人气 / 最新上架（服务端 `o` 参数，切换即从第 1 页重拉）。
- **修复**：阅读器进度条拖动无效；「已收藏」提示黑条常驻；评论全部误带「剧透」标；双指刚落下时误翻页。

## 升级提示

- 覆盖安装即可，数据全部沿用：收藏账本、阅读进度与历史、下载历史、登录态（0.3.2 起密码存在系统密钥库，不会因升级失效）。
- 「界面材质 Metal / LiquidGlass（iOS 27 液态玻璃）」属于**尚在开发的 0.4.0**，本版不含，不要拿这个包验证液态玻璃 UI。
